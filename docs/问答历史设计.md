```sql
CREATE TABLE qa_history (
    id INTEGER PRIMARY KEY,
    created_at TEXT NOT NULL,
    question TEXT NOT NULL,
    answer TEXT,
    refused INT NOT NULL,
    status INT NOT NULL,
    error TEXT
    );
```
```sql
CREATE TABLE qa_sources(
    qa_id INTEGER NOT NULL REFERENCES qa_history(id),
    rank INT NOT NULL,
    chunk_id TEXT NOT NULL,
    doc_id TEXT NOT NULL,
    PRIMARY KEY (qa_id, rank)
    );
```
路径：/history
方法：GET
参数：refused limit
默认值:不传 10
refused:不传时查全部  传false查为0  传true查为1
范围：  1-100
排序：ORDER BY id DESC LIMIT ?
返回内容：符合条件的历史记录
写入失败时，照常返回 200 和回答，用 logger.error 记下写入失败。用户不受影响，我们看日志也能发现问题。  limit不在范围内时 返回422
